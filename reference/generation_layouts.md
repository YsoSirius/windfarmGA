# Layouts evaluated in one generation

Return every individual that was fitness-evaluated in a given generation
(`allCoords`). Duplicate layouts (same cell IDs) are flagged.

## Usage

``` r
generation_layouts(result, generation = NULL)
```

## Arguments

- result:

  The output of
  [`genetic_algorithm`](https://YsoSirius.github.io/windfarmGA/reference/genetic_algorithm.md)

- generation:

  Generation index (1 = first). Default is the last generation in
  `result`.

## Value

A list with `turbines` (one row per turbine), `layouts` (one row per
individual) and `generation`.
